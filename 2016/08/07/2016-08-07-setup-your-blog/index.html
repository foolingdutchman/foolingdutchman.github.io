##Mac上搭建基于GitHub的Hexo博客

$ sudo npm install -g hexo

$ hexo init blog

$ npm install

$ hexo s

$ vim _config.yml

$ hexo generate 或者：hexo g

ERROR Local hexo not found in ~/blog ERROR Try runing: &apos;npm install hexo --save&apos;

npm install hexo --save

$ hexo deploy 或者：hexo d

$ npm install hexo-deployer-git --save

Username for &apos;https://github.com&apos;: Password for &apos;https://github.com&apos;:

$ ls -al ~/.ssh

$ ssh-keygen -t rsa -C &quot;your_email@example.com&quot;

hexo new &quot;postName&quot;

hexo generate //生成静态页面 hexo deploy //将文章部署到Github

$ git clone https://github.com/iissnan/hexo-theme-next themes/next

$ hexo clean //清除缓存文件 (db.json) 和已生成的静态文件 (public) $ hexo g //生成缓存和静态文件 $ hexo d //重新部署到服务器

$ hexo clean $ hexo g $ hexo d
```大功告成！
